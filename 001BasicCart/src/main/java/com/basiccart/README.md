# Basic cart 001

A console-based Java application built to master programming fundamentals through hands-on iteration.

## 🚀 Iteration 001 Basic Cart 

[First Version: a simple app for users to browse through a list of predefined products and manage a shopping cart, (add, view, remove items from cart)]


## 🧠 What I Learnt
* [I learned variables, if-else statements, loops(for, while), implemented the scanner variable. Used an array to store the items in cart or in-stock, also arrays have fixed so to work with them teaches usage of index(item positioning within)]


## 💻 How to Run
```bash
# Compile the code
javac src/App.java 

# Run the app
java App.java
```
